# SwiftMacro UI assets

Generated pixel-art PNGs inspired by the supplied UI reference sheet.
Run `python tools/generate_ui_assets.py` to rebuild the atlases and crops.

- `icons/`: standalone transparent pixel icons
- `textures/`: repeating Minecraft-inspired material tiles
- `buttons/`: normal, hover, pressed and disabled button faces
- `*_atlas.png`: source atlases; `asset_catalog.png` is a preview sheet
